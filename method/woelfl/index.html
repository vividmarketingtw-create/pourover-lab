沖煮步驟 — 15g 粉的配方（15g / 239g）

悶蒸 + 三段主注水
  1. 1. 第一注（悶蒸）
    時間 0:00 · 注水 53g · 注到 53g · 40秒
    93°C，注入 53g（總水量 22%、約粉量 3.5 倍，比一般配方多），輕搖濾杯讓粉均勻濕潤。等到 0:40 再注第二注 — 四注的起注時間固定在 0:00 / 0:40 / 1:20 / 2:00（原法值，不隨粉量或「我的流速」改變）。
    研磨參考：小飛馬600N 刻度 3.5-4｜Comandante 約21-24格 / 1Zpresso JX 約2.1-2.4圈
    📏 研磨兩說：他自己的烘豆公司 Wildkaffee 公布的是 630µm；European Coffee Trip 記載的是 490µm（Comandante C40 約 21-25 格）。兩個都是公開數字，本站不擅自判定 — 建議從中間起步，再依總時間調整。
    ℹ️ 冠軍原版：17g／270g（1:15.9）、93°C、Orea V4（Narrow＋Fast 底座）＋ Sibarist FAST 濾紙，另用 Melodrip 分水器與針式布粉器，比賽現場現磨。四注 60 / 60 / 50 / 100g，0:00 / 0:40 / 1:20 / 2:00 起注，2:20 注完、2:20-2:25 落完。
    ⏱ 畫面上的時間是以 Hario V60 為基準算的（本站所有沖法都是）。若你真的用 Orea V4 Fast ＋ Sibarist FAST，會比畫面快 20-30 秒、更接近原版的 2:20-2:25；反之用 V60＋標準濾紙時畫面時間就是你該看到的。
  2. 2. 第二注
    時間 0:40 · 注水 53g · 注到 106g · 40秒
    93°C，約 11 秒注入 53g，中心小圈穩定注水（約 4.8 g/s）。注完等到 1:20 再注下一注。
  3. 3. 第三注
    時間 1:20 · 注水 44g · 注到 150g · 40秒
    93°C，約 9 秒注入 44g，維持同樣手法。注完等到 2:00 再注最後一注。
  4. 4. 第四注（最大注）
    時間 2:00 · 注水 89g · 注到 239g · 18秒
    最後一注最大量 89g（約 18 秒，佔總水量 37.5%），略拉高水位帶動翻攪 — 這是此法唯一一次比較積極的擾動。注完就不要再碰。
  5. 5. 等待滴完
    時間 注完後 · 維持 239g · 25秒
    快濾紙下水極快，滴完即完成，畫面上的目標約 2:43（V60 基準）。
    💡 原版用 Orea V4 Fast ＋ Sibarist FAST 在 2:20-2:25 落完，幾乎不需要等滴濾。若你的總時間比畫面長很多，研磨調粗半格；比畫面短很多且偏酸，研磨調細半格。冠軍原版堅持現場現磨。

完整沖法指南

由來

奧地利咖啡師 Martin Wölfl 的 2024 年世界沖煮杯（World Brewers Cup）冠軍配方。競賽原版：17g / 270g（1:15.9）、93°C、Orea V4（Narrow＋Fast 底座）＋ Sibarist FAST 濾紙，搭配 Melodrip 分水器與針式布粉器，並堅持比賽現場現磨。四注 60 / 60 / 50 / 100g，起注 0:00 / 0:40 / 1:20 / 2:00，總時間 2:20-2:25。

核心概念

核心是「高流速、短時間」：用快濾杯＋快濾紙把總時間壓在 2 分半以內，讓萃取停在最乾淨明亮的區間。四注遞進（22% 悶蒸 → 22% → 18.5% → 37.5% 最大注）在短時間內完成均勻萃取，最後一注拉高水位帶動翻攪 — 這是全程唯一一次比較積極的擾動。起注間隔固定 40 秒。

操作重點

  • 起注時間固定 0:00 / 0:40 / 1:20 / 2:00（原法值，本站已鎖定，不隨粉量或流速設定改變）
  • 悶蒸水量約粉量 3.5 倍（總水量 22%），比一般配方多
  • 四注水量 60 / 60 / 50 / 100g，最後一注最大（37.5%）拉高水位帶動翻攪
  • 全程 93°C；原版器材下總時間 2:20-2:25
  • 關鍵器材：Orea V4 Fast 底座 ＋ Sibarist FAST 濾紙（也可用 April 等快流速濾杯），另有 Melodrip 與針式布粉器
  • 研磨兩說：Wildkaffee（他自己的烘豆公司）寫 630µm；European Coffee Trip 寫 490µm（Comandante C40 約 21-25 格）。建議從中間起步再依總時間調整
  • ⏱ 本站顯示的時間一律以 Hario V60 為基準；用原版的快濾杯＋快濾紙會比畫面快 20-30 秒

適合的豆子

淺焙、花果調性的高品質豆 — 短萃取最能放大乾淨的酸質與香氣

比較不適合

中深焙或想要厚實 body 的場合（短萃取會顯得單薄）

常見問題

沒有快流速濾杯／快濾紙
V60＋標準濾紙完全可以沖 —— 本站畫面上的時間本來就是 V60 基準，照著走即可。想更接近原版的 2:20 可以研磨調粗半格
太酸太銳利
研磨調細半格 — 短萃取下偏酸通常代表萃取率不足。也可確認最後一注有確實拉高水位帶動翻攪
總時間比畫面長很多
研磨太細或細粉太多，調粗半格；若每次都偏長，用「我的流速」往慢調校正等待
風味很淡
此法口感本來就輕盈；想更有存在感可將粉水比從 1:15.9 收到 1:15
630µm 和 490µm 差這麼多，要信哪個
兩個都是公開資料 — Wildkaffee 是他自己的公司、ECT 是媒體整理。建議從中間（約飛馬 3.5-4）起步，用總時間當判斷依據往上或往下調，比糾結微米數實際
